# Maya Lighting Template for VFX & Animation Pipelines

A production-oriented Maya lighting template designed to provide a clean, scalable, and standardized scene hierarchy for look development, lighting, rendering, and compositing workflows.

This template organizes assets, lights, volumes, projections, utilities, and render layer collections into a structured layout, making shot management easier for artists and ensuring consistency across productions.

## Features

### Scene Hierarchy Organization

* Structured **World → Geo → ShotPKG** asset hierarchy.
* Dedicated groups for:

  * Cameras
  * Characters
  * Props
  * Environment
  * Crowd
  * FX
  * Data
  * USD Assets

### Lighting Framework

* Predefined lighting groups:

  * **Dome** – HDRI and environment lighting
  * **Key** – Primary lighting sources
  * **Bloom** – Fill, rim, and highlight lights
  * **Extra_Lights** – Shot-specific lighting
  * **Filters** – Gobos, blockers, barn doors, and cookies

### Utility Tools

* Reference spheres for lighting calibration:

  * Grey Ball
  * Chrome Ball
  * Macbeth Chart
* Organized utility objects for lookdev and troubleshooting.

### Volume Support

* Dedicated volume container for:

  * Fog
  * Smoke
  * Clouds
  * Atmospheric effects

### Projection Workflow

* Camera projection setup for:

  * Matte paintings
  * Environment extensions
  * Projection-based workflows

### Render Layer Collections

Includes organized collections for:

* Camera Objects
* Trace Objects
* Light Objects
* Matte Objects

Designed to simplify Arnold render setup, AOV management, and compositing workflows.
